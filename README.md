# Population Analysis Dashboard | Power BI

## Project Overview

An interactive **Population Analysis Dashboard** built using **Power BI** to analyze demographic data across Indian cities and states. The dashboard provides insights into population, literacy, graduates, gender distribution, children population, and sex ratios.

## 🎯 Objectives

- Analyze population distribution across different states and cities.
- Compare literacy and graduate statistics.
- Understand male and female population patterns.
- Identify important demographic trends using interactive visualizations.

## 📂 Dataset

The project uses a city-level demographic dataset containing **493 cities and 22 attributes**.

The dataset includes:

- City and State information
- Total, Male, and Female Population
- Children Population (0–6 years)
- Total, Male, and Female Literates
- Overall, Male, and Female Literacy Rates
- Sex Ratio and Child Sex Ratio
- Total, Male, and Female Graduates
- Geographic Location

##  Dashboard Features

- Total Population KPI
- Male and Female Population
- Total Literates
- Total Graduates
- Top 5 Cities by Population
- State-wise City Analysis
- State-wise Children Population
- Gender-wise Literacy Analysis
- Top States by Graduates
- Highest Sex Ratio Cities
- Interactive State Filter

##  Tools & Technologies

- **Power BI**
- **Power Query**
- **DAX**
- **Data Cleaning & Transformation**
- **Exploratory Data Analysis**
- **Data Visualization**

##  Key Insights

The dashboard helps identify:

- Cities with the highest population.
- States with the highest number of graduates.
- Differences in male and female literacy rates.
- Population distribution across states.
- Cities with higher sex ratios.
- State-wise demographic patterns.
